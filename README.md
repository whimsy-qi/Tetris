# 终端俄罗斯方块

在本机系统终端里用键盘玩的固定尺寸俄罗斯方块：10 列 × 20 行棋盘，支持**单人 / 双人**两种模式。单人用 `A/D/S/W` 操作；双人时左板 `A/D/S/W`、右板方向键，两块棋盘同时下落。满行消除每行 100 分，新方块放不下时结束。需求与验收以 `spec.md` 为准。

## 系统要求

- Python 3.8 或更高版本（Windows 用 `py`，macOS/Linux 用 `python3`）。
- 终端窗口：单人至少 **40 列 × 28 行**，双人至少 **46 列 × 26 行**，否则不能进入游戏。
- **不需要安装任何第三方包**，只用 Python 标准库。

## 启动

```
py tetris.py          # Windows
python3 tetris.py     # macOS / Linux
```

启动后先选模式：`1` 单人、`2` 双人、`Q` 退出。

## 测试

```
py -m unittest test_game_logic.py          # Windows
python3 -m unittest test_game_logic.py     # macOS / Linux
```

测试只覆盖 `game_logic.py` 的规则逻辑，不启动终端界面。

## 按键（按下即生效，无需回车）

| 功能 | 单人 | 双人 |
| --- | --- | --- |
| 左移 / 右移 | `A` / `D` | P1 `A` / `D`，P2 `←` / `→` |
| 下移一格 | `S` | P1 `S`，P2 `↓` |
| 顺时针旋转 | `W` | P1 `W`，P2 `↑` |
| 暂停 / 继续 | `P` | `P`（双方同时） |
| 重开一局 | `R` | `R`（保持当前模式） |
| 切换模式 | `M` | `M`（切到另一模式并重开） |
| 退出 | `Q` | `Q` |

其他按键会被忽略，不报错。

## 规则摘要

- 七种方块（I、O、T、S、Z、J、L）各自独立等概率随机。
- 方块每 0.5 秒自动下落一行；落到棋盘底部或已有方块上就固定。
- 满行一次清除，上方内容下移、顶部补空行；每行 100 分。
- 连击：连续消行时第 2 次起每次得分翻倍（2 倍，不叠乘）；中间有一次没消行就清零。
- 双人：两块棋盘、两套分数互不干扰；任一方新方块放不下即整局结束，另一方获胜，同时放不下为平局。
- 按 `P` 暂停后，棋盘、方块位置、分数都不变，恢复后从原局面继续。
- 新方块在出生位置放不下时游戏结束，显示最终得分；按 `R` 重开或 `Q` 退出。
- 终端缩小到不足当前模式所需尺寸时自动暂停并提示，恢复后继续；若缩小前是手动暂停，恢复后仍保持暂停。

| 文件 | 内容 |
| --- | --- |
| `game_logic.py` | 棋盘、方块、碰撞、旋转、消行、计分、对局与模式（纯逻辑，不读按键、不画屏幕） |
| `tetris.py` | 终端显示（单人/双人）、按键读取、模式菜单、定时下落循环、入口 |
| `test_game_logic.py` | 不依赖终端界面的逻辑测试（unittest） |
| `spec.md` | 需求与验收条件 |
| `AGENTS.md` | 项目工作约定（含 Git 约定） |
| `process.md` | 计划、TDD 记录与验收记录 |
