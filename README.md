# 终端俄罗斯方块

在本机系统终端里用键盘完整玩一局固定尺寸的俄罗斯方块：10 列 × 20 行棋盘，A/D 移动、S 软降、W 顺时针旋转、P 暂停/继续、R 重开、Q 退出，每 0.5 秒自动下落，满行消除每行 100 分，新方块放不下时结束。需求与验收以 `spec.md` 为准。

## 系统要求

- Python 3.8 或更高版本（Windows 用 `py`，macOS/Linux 用 `python3`）。
- 终端窗口不小于 **40 字符列 × 28 字符行**，否则不能进入游戏。
- **不需要安装任何第三方包**，只用 Python 标准库。

## 启动

```
py tetris.py          # Windows
python3 tetris.py     # macOS / Linux
```

## 测试

```
py -m unittest test_game_logic.py          # Windows
python3 -m unittest test_game_logic.py     # macOS / Linux
```

测试只覆盖 `game_logic.py` 的规则逻辑，不启动终端界面。

## 按键（按下即生效，无需回车）

| 键 | 作用 |
| --- | --- |
| A / a | 左移 1 列 |
| D / d | 右移 1 列 |
| S / s | 立即下移 1 行，并重置自动下落计时 |
| W / w | 顺时针旋转 90° |
| P / p | 暂停 / 继续 |
| R / r | 重开一局 |
| Q / q | 退出（任意状态有效） |

其他按键会被忽略，不报错。

## 规则摘要

- 七种方块（I、O、T、S、Z、J、L）各自独立等概率随机。
- 方块每 0.5 秒自动下落一行；落到棋盘底部或已有方块上就固定。
- 满行一次清除，上方内容下移、顶部补空行；每行 100 分。
- 新方块在出生位置放不下时游戏结束，显示最终得分；按 R 重开或 Q 退出。
- 终端缩小到不足 40×28 时自动暂停并提示，恢复后继续；若缩小前是手动暂停，恢复后仍保持暂停。

## 文件

| 文件 | 内容 |
| --- | --- |
| `game_logic.py` | 棋盘、方块、碰撞、旋转、消行、计分（纯逻辑，不读按键、不画屏幕） |
| `tetris.py` | 终端显示、按键读取、定时下落循环、入口 |
| `test_game_logic.py` | 不依赖终端界面的逻辑测试（unittest） |
| `spec.md` | 需求与验收条件 |
| `AGENTS.md` | 项目工作约定 |
| `process.md` | 计划、TDD 记录与验收记录 |
